## Changes

New live generation requires six ordered primary stages: Hook → Problem → Pattern Interrupt → Value → Payoff → one final CTA. There are at least six production shots; stages can contain additional shots and use unequal timings. Three shots carrying combined function tags cannot pass. Old saved stories retain their actual scene lists, optional functions and original timing. The new contract survives validation, sharing and saved-content snapshots; incomplete new-stage stories cannot receive editorial approval.

The editor presents six stage links targeting actual production cards. Keyboard navigation moves focus to the shot. No missing scenes are invented for older records.

Writing prompts now request a specific, accessible academic example, natural student speech, a practical HLNI and an observable consequence. Planning preserves the proposed concrete payoff instead of replacing it with the generic tool rule. Draft speech targets leave headroom below hard timing limits. A narrow English regression check catches the observed activity-to-degree recommendation. Conflicting advisory requests to remove the comparison or invent typical assessment associations are discarded; this is not a universal factual verifier.

The last fix preserves already-visible selected example/question graphics during English speech compression. It restores only original captions containing the selected anchors, adds no spoken words or new claims, and still runs normal QA. It addresses a concrete failed repair seen in run 03. The run manifest now includes outputRepair.ts for future source hashing.
