## Scoring method and hard gates

Each editorial rating is 0–5: 0 missing, 1 poor, 2 weak, 3 partial, 4 strong, 5 exceptional. Weighted total = Σ(weight × rating / 5). Apply the user's proposed thresholds: total ≥85, HLNI ≥4 and differentiation ≥4. Material factual errors, missing meaningful insight and unworkable production instructions independently trigger revision. These are reasoned editorial judgements, not an objective measurement of creativity.

No external curriculum source audit was performed. An unsupported claim is not labelled proven false: material-factual-error triggers are therefore not asserted. References still require verification before using apparent document evidence.

## Cross-channel finding and highest-leverage revision

All three open with “Everyone says”, inspect papers/module lists, highlight overlap and end with confident advice. Connection adds an actor but no meaningful interaction; Discovery supplies a function tag without a genuinely surprising educational reveal. Surface variation does not satisfy channel differentiation.

The current engine locks the comparison's intended takeaway to comparing modules/assessment tasks before the creative concept is selected; changing the audience or adding benchmark summaries has not overcome that narrowing. The generation logs also report territory collisions, yet the returned concepts remain alike. This is a concrete engine-level revision target, not evidence that the flexible framework should be made rigid again.

Next revise concept/HLNI selection so the topic and entities stay locked while the insight, human tension and storytelling opportunity can differ. Ground factual insights in actual supplied sources; otherwise demonstrate a specific reasoned method. Compare the actual chosen concepts across channels before writing production shots, then evaluate a new separately archived run using this same rubric. Keep these failed outputs as the baseline; do not overwrite them or treat passing metadata checks as creative approval.
