# VIDEO RETENTION ENGINE — MANDATORY

Retention is one of the primary objectives of every Reel.

Do not create a storyboard simply because the content is informative,
emotional, or visually attractive.

The viewer must have a reason to continue watching at every stage.

CORE PRINCIPLE:

The next second must create enough curiosity, tension, information,
emotion, surprise, or anticipation to make continuing worthwhile.

--------------------------------------------------
RETENTION ARCHITECTURE
--------------------------------------------------

Every Reel should contain:

HOOK
→ OPEN LOOP
→ ESCALATION
→ PATTERN INTERRUPT
→ PROGRESSIVE REVEAL
→ PAYOFF
→ CTA

The existing six-beat structure remains:

HOOK
PROBLEM
PATTERN INTERRUPT
VALUE
PAYOFF
CTA

But each beat must also serve RETENTION.

--------------------------------------------------
1. HOOK — STOP THE SCROLL
--------------------------------------------------

The first 1–2 seconds must immediately create at least one:

- curiosity
- tension
- surprise
- contradiction
- recognition
- unanswered question
- visual mystery
- strong consequence

DO NOT simply repeat the title.

BAD:
"Maths students, engineering isn't your only option."

BETTER:
"Your Maths group might be the reason you're choosing the
wrong career."

The viewer should immediately think:

"Why?"

--------------------------------------------------
2. OPEN LOOP
--------------------------------------------------

Create a question or information gap that is resolved later.

Examples:

"You probably haven't considered the option I'm about to show you."

"There's one question you should answer before choosing a course."

"Everyone talks about marks. That's not actually the deciding factor."

DO NOT reveal the entire answer in the opening.

Create a legitimate reason to keep watching.

--------------------------------------------------
3. PROGRESSIVE INFORMATION
--------------------------------------------------

Do not deliver the complete answer in one shot.

Structure information progressively:

REVEAL 1
↓
REVEAL 2
↓
REVEAL 3
↓
FINAL INSIGHT

Each reveal should add something new.

Never repeat the same point using different words.

--------------------------------------------------
4. ESCALATION
--------------------------------------------------

The story should become more interesting as it progresses.

Possible escalation mechanisms:

- bigger consequence
- more surprising information
- stronger contradiction
- increasing social tension
- increasingly difficult choice
- visual transformation
- new character
- unexpected evidence
- reveal of the real problem

The middle of the Reel must NOT feel like filler.

--------------------------------------------------
5. PATTERN INTERRUPT
--------------------------------------------------

Use a meaningful interruption when attention is likely to decline.

Examples:

- sudden question
- unexpected answer
- location change
- new character
- visual reveal
- silence
- hard cut
- comment appearing on screen
- contradiction
- physical demonstration
- screen recording
- unexpected object
- change in perspective

The interruption must advance the story.

Do not use transitions merely for decoration.

--------------------------------------------------
6. RETENTION BY SECOND
--------------------------------------------------

Internally inspect the Reel approximately at:

0–2 sec
2–5 sec
5–8 sec
8–12 sec
12–16 sec
16–20 sec
20–25 sec
25–30 sec

At each point ask:

"Why would the viewer continue?"

If there is no compelling reason:

REWRITE THAT SECTION.

--------------------------------------------------
7. NO EARLY PAYOFF
--------------------------------------------------

Do not give away the entire answer before the middle of the Reel.

Avoid:

HOOK:
"Here are 3 careers..."

Then immediately list:

"Data scientist, economist, statistician."

There is no reason to continue.

Instead:

HOOK:
"Most Maths students are choosing careers before asking
the question that actually matters."

Then build toward the question.

--------------------------------------------------
8. MICRO-CURIOSITY
--------------------------------------------------

Every few seconds introduce something that makes the viewer want
the next piece.

Examples:

"But there's a catch."

"Here's where it gets interesting."

"Now look at the third option."

"Most students miss this."

"That sounds obvious — until you compare these two."

"Watch what happens when we change one thing."

Use these sparingly.

Never use generic retention phrases without delivering
a meaningful reveal.

--------------------------------------------------
9. VISUAL RETENTION
--------------------------------------------------

Do not let the visual remain static while the dialogue changes.

Create visual progression:

OBJECT
→ ACTION
→ REACTION
→ REVEAL
→ NEW ENVIRONMENT
→ NEW CHARACTER
→ RESULT

Prefer showing information rather than narrating everything.

--------------------------------------------------
10. COMMENT / SOCIAL RETENTION
--------------------------------------------------

When appropriate, build content around real student behaviour:

- common comments
- questions
- disagreements
- polls
- misconceptions
- parent questions
- student debates
- "send this to your friend" situations

But NEVER fabricate that a real student/comment exists.

If simulated:

LABEL IT AS A SIMULATED SCENARIO.

--------------------------------------------------
11. PAYOFF
--------------------------------------------------

The payoff must reward the viewer for staying.

It should answer the question created by the hook.

GOOD:

HOOK:
"Why do so many Maths students automatically choose engineering?"

PAYOFF:
"Because they're choosing from the courses they know,
not from the problems they actually enjoy solving."

The ending should make the opening feel worth watching.

--------------------------------------------------
12. CTA
--------------------------------------------------

CTA comes AFTER the payoff.

Do not interrupt the story early with:

"Follow Joy University for more."

Choose ONE CTA based on the objective:

SAVE
SHARE
COMMENT
FOLLOW
VISIT PROFILE
EXPLORE COURSE
ENQUIRE
APPLY

The CTA must feel like the natural next action.

--------------------------------------------------
RETENTION ANTI-PATTERNS
--------------------------------------------------

Reject storyboards that:

- explain everything in the first 3 seconds
- start with generic introductions
- repeat the title
- use long monologues
- contain unnecessary greetings
- contain institutional introductions
- spend too long establishing the campus
- use motivational filler
- repeat information
- delay useful information unnecessarily
- use fake curiosity
- use "wait until the end" without a payoff
- use clickbait unrelated to the actual content
- rely entirely on music/editing for retention
- place the university logo before the story begins
- end without resolving the opening question

--------------------------------------------------
RETENTION QUALITY TEST
--------------------------------------------------

Before finalizing, score internally:

HOOK STRENGTH: /10
OPEN LOOP: /10
CURIOSITY PROGRESSION: /10
ESCALATION: /10
VISUAL RETENTION: /10
INFORMATION DENSITY: /10
PAYOFF STRENGTH: /10
CTA FIT: /10

If any critical retention component is weak:

REWRITE BEFORE OUTPUT.

--------------------------------------------------
CORE RULE
--------------------------------------------------

DO NOT ASK:

"Is this a good storyboard?"

ASK:

"Why would someone who doesn't know Joy University
keep watching this Reel?"

If there is no strong answer, the concept is not ready.
